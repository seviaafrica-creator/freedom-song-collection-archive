# Let Freedom Be Our Legacy — Freedom Song Archive

An anthem for human rights activists. Original lyrics, original music —
nothing sampled or adapted from any existing song.

**The song:** starts with one voice completely alone, then the bass guitar
enters, then the piano, then drums and dondo (talking drum), then the entire
band — one voice becoming a crowd.

## Listen

Play every take and download the current best at **[anthem.html](anthem.html)**
or browse the full archive at **[index.html](index.html)** — this repository
serves both as a website via GitHub Pages and as the permanent file backup.

## Files

- `audio/` — every recorded take (MP3)
- `lyrics-take12.txt` — the final lyric sheet
- `style-prompt-take12.txt` — the sound recipe for the master
- `suno-pack.txt` — everything needed to rebuild/improve the song on suno.com
- `README.txt` — the full catalog with notes on every take
